# Second Brain

A lightweight documentation & Notion setup for a personal "Second Brain" system.

## Overview
This repository stores notes and Notion setup pages used to build a Second Brain system: project and task databases, views, automations and formulae.

## Repo structure
- `Second Brain Notion Setup/` — main markdown specs (Setup.md, Databases.md, LifeOs.md, etc.)
- `Images/` — image assets referenced from the docs

## Usage
- Read `Second Brain Notion Setup/Setup.md` to get started.
- Open `Second Brain Notion Setup/Databases.md` for database-specific fields and formulae.

## Notes
- `.gitignore` contains common ignores (e.g. `.DS_Store`). If files still appear tracked after adding rules, they must be removed from the index with `git rm --cached`.

## Contributing
Feel free to open issues or PRs. For quick edits, you can update the markdown files directly and commit.
